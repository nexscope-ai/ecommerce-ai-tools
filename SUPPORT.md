# Official Nexscope support

Use [Discussions Q&A](https://github.com/nexscope-ai/ecommerce-ai-tools/discussions/categories/q-a) for usage questions about Nexscope tools, APIs, and REST/MCP integrations. Use [Discussions Ideas](https://github.com/nexscope-ai/ecommerce-ai-tools/discussions/categories/ideas) to explore a new workflow or capability. Use [Issues](https://github.com/nexscope-ai/ecommerce-ai-tools/issues/new/choose) for reproducible bugs and feature requests that the team can track. For an API bug, choose **API Docs / REST / MCP** in the form and include the endpoint slug and a redacted request or error example.

The official Nexscope team checks public Q&A and Issues on business days and aims to acknowledge new, actionable reports within one business day. This is a response target, not a guaranteed resolution time. Private account, billing, and security matters should go to [private support](mailto:service@nexscope.ai).

## Choose the right channel

- **Q&A:** name the tool or endpoint, describe what you are trying to do, what you tried, and where you got stuck.
- **Ideas:** describe the workflow you want, your expected output, and how you currently handle it.
- **Bug report Issue:** describe the expected and actual behavior, steps to reproduce, and any non-sensitive error code.
- **Feature request Issue:** explain a trackable product gap, your goal, and your current workaround.

Search existing Discussions and Issues first. Add relevant details to an existing thread or report when it describes the same problem.

## What happens next?

1. We first confirm what the user is trying to do, state what is verified, and ask for only the missing non-sensitive details needed to investigate. If an answer is available, we provide the steps or link to the relevant guide.
2. When a Q&A answer resolves the question, we mark it as the answer. If a reproducible product change is needed, we link a tracked Issue from the discussion and use that Issue for implementation updates.
3. When the fix, documentation change, or other outcome is available, we return to the original discussion with the result. We do not claim a fix is complete before it is verified. An Issue can be closed after a fix is available or an existing report covers the same problem.

If a public post has not received an initial response after one business day, link the original thread when following up rather than opening a duplicate.

## Private information

Issues are public. Never include passwords, API keys, access tokens, payment details, or customer data. Redact screenshots and logs.

For private account, billing, or sensitive security questions, email [service@nexscope.ai](mailto:service@nexscope.ai). Describe the problem without sending your password or access token.
