# Product photography prompt pack

Suggested inputs, not measured outputs. Use a product reference you have permission to send. Replace bracketed descriptions with verified facts, and remove any detail you cannot verify. A prompt requests consistency but does not guarantee it.

## Clean studio draft

Change only the background to plain white with a soft contact shadow. Preserve the supplied item, label, cap, color, proportions and visible quantity. Keep the whole product visible. Add no props, contents, claims or text.

## Lifestyle concept

Place the supplied [exact item] in [one relevant setting]. Use natural side lighting and a realistic contact shadow. Preserve the item, variant, printed label, dimensions relative to approved reference objects and included pieces. Add no unsupported feature, accessory, contents or person using it in an unverified way.

## Ad-layout concept

Place the supplied item on [approved background] with empty space on the [left/right] for copy added later. Keep the product label and all visible details unchanged. Add no discounts, certification marks, testimonials or generated text.

## Review every result

Compare reference and output for identity, proportions, label, color, count and implied use. Inspect the destination's current requirements separately. Save prompt, model, settings, output, credits and the approval or rejection reason. A visually attractive image can fail an exact-product check.
