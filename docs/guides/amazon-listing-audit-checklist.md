# Amazon Listing Audit Checklist: Find the First Fix for One ASIN

Start an Amazon listing audit with one child ASIN and one marketplace. Determine whether buyers struggle to find the listing, understand the offer or distinguish it from competing options. The same listing can have different issues for different searches.

## Audit what buyers see, in order

1. **Confirm the offer.** Open the public listing in the target marketplace and select the exact size or pack. Record the title, main image, selected option and what ships. Check that the content matches the packaging or specification sheet.
2. **Compare the listing with one buyer query.** Search the phrase a buyer would use. Choose two comparable listings in the same market. Note which product attributes they communicate early, such as dimensions, fit or included parts. Mark sponsored placements before using search results as a comparison set.
3. **Read the images as a buyer.** Identify the first question an image leaves unanswered. If customers must know whether a part fits a 22 mm bar, compare that measurement against the product specs and put it in a suitable image or bullet. Follow the image requirements for the relevant marketplace and category. [Amazon’s listing guide](https://sell.amazon.com/blog/amazon-product-listings?mons_sel_locale=en_US)
4. **Check reviews for recurring uncertainty.** Record repeated questions about the product and variant. Confirm the actual specifications before turning any review claim into listing copy.

## Choose one change to verify

Imagine a two-pack handlebar mount shown installed on two bicycles. If the selected variant ships one mount, resolve that conflict before polishing the headline. If the pack count is accurate and buyers still struggle with fit, clarify compatible diameters and what adapters are included. For a real worked example, see the [paint roller kit listing audit]({{ '/guides/amazon-listing-audit-paint-roller/' | relative_url }}).

Write down the hypothesis, the exact content change and the metric you plan to check. Eligible sellers and ASINs can use Manage Your Experiments for supported listing changes. Record price, inventory and promotions if you compare performance before and after an edit. [Amazon Manage Your Experiments](https://sell.amazon.com/tools/manage-your-experiments?mons_sel_locale=en_US)
