## How to create a product video from images

1. Open the tool and sign in with your Nexscope account. The page opens a login window when authentication is needed.
2. Choose a model. **Seedance 2.0 Mini is the initial selection.** Compare the available resolution, duration, image inputs, and credit estimate for your intended output.
3. Upload a clear product image or the reference images supported by that model. Use a sharp image that shows the product's shape and label.
4. Write a motion prompt. Specify the camera movement, product movement, scene, and details that should remain consistent.
5. Select the available duration, resolution, and aspect ratio. Check the displayed seconds and estimated credits before generating.
6. Generate the video. Model and parameter controls are locked while generation is running. If credits are insufficient, the page offers a subscription entry point.
7. Preview the result and inspect product fidelity before downloading or using the clip in a campaign.

The workflow runs in the hosted Nexscope tool. This repository contains its documentation and support resources, not a local video-generation engine.

## An example prompt for a product image

For an image of a reusable water bottle, try:

> Create a slow, smooth camera orbit around the bottle on a clean studio surface. Keep the bottle shape, cap, colors, and printed label consistent with the reference image. Use soft side lighting and a subtle reflection. Keep the bottle upright throughout the shot.

This is a suggested input, **not a measured generation result**. Start with one simple movement, inspect the output, and change one instruction at a time. Do not treat a prompt as a guarantee that every detail will be preserved.

## Review the result before publishing

| Check | What to inspect | If it fails |
| --- | --- | --- |
| Product identity | Shape, logo, packaging text, color, and proportions | Simplify motion or choose a clearer reference, then review a new generation. |
| Motion | Distortion, flickering, unexpected object movement | Reduce the number of requested actions. |
| Framing | Product visibility and room for captions in the target aspect ratio | Adjust framing instructions and output ratio. |
| Claims | Scenes that suggest untested performance, capacity, or durability | Remove unsupported implications before using the clip. |

For a reproducible comparison, record the input image, prompt, model, selected settings, date, actual credits used, and your review notes. Save the output alongside those inputs. A model-generated clip is creative material; it is not evidence of product performance.
