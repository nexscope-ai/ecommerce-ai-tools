# How to run an Amazon Black Friday competitor audit for one ASIN

Amazon's US Black Friday Week and Cyber Monday events run November 19–30, 2026. Pick one child ASIN and one buyer question before opening competing listings. If you sell a travel mug, ask which offers are suitable for someone who needs a mug that fits a narrow cup holder. Compare three offers a shopper could reasonably choose for that purpose. [Amazon's official event announcement](https://press.aboutamazon.com/2026/11/amazons-black-friday-week-and-cyber-monday-return-november-19-30-with-millions-of-deals-to-deliver-joy-this-holiday-season)

## Build a comparison that matches how buyers choose

Use a category keyword in the same marketplace and keep the child ASIN for each candidate. Open each listing and verify pack size, the selected variant and what is included. Keep sponsored placement and search order out of your assessment of product fit. Search is a way to find candidates for the comparison.

| Field to save | How to use it |
| --- | --- |
| Marketplace, child ASIN and date | Make the comparison reproducible during and after the event |
| Pack size, size and accessories | Check whether the competing product serves the same need |
| Observed price and discount terms | Label Prime, coupon and bundle conditions alongside the observed price |
| Delivery estimate | Capture it for a consistent destination and timestamp |
| Proof on the listing | Save the exact bullet, image or specification that supports the buying decision |

A $24 mug with one lid and a $30 set with two lids can both be relevant alternatives. Show what each offer includes before interpreting the price difference. If your page has no verified base diameter, measure it before adding a fit claim. If a competing listing omits its measurement, record it as unknown.

## Turn the comparison into one listing improvement

Pick the gap most closely tied to the buyer's question. For the mug, that could be a dimension image showing the measured base diameter, or a clearer bullet describing the lid and included parts. Save the source for the claim and review the exact listing again before sending more traffic.
