# What ecommerce sites should check during Google's November 2026 core update

Google's Search Status Dashboard shows that the November 2026 core update began November 10 Pacific time. The dashboard listed the rollout as active when checked on November 13. Save a baseline now so you can compare the same product pages and queries once the rollout has finished. [Google Search Status Dashboard](https://status.search.google.com/)

## Save a baseline while the update runs

In Search Console's Performance report, export clicks, impressions, CTR and average position for the pages you plan to compare. Keep the search type, country, device filters and date range with each export. Include a week before rollout and record any site changes, holiday promotions or inventory changes that overlap the dates.

| What changed? | What to record or check |
| --- | --- |
| Impressions and position both fell | Save affected page and query pairs, then check whether the change is isolated to a category or template |
| Impressions held while clicks fell | Review CTR and changes to the search results for the same queries |
| One variant stopped receiving traffic | Check the live URL, canonical and indexing state |
| One product page lost clicks during a sale | Record price, stock and promotion changes that may affect comparison |

Fix independently confirmed problems such as a broken product URL or an unintended indexing directive when you find them. Keep a dated record so those repairs are visible in the later analysis.

## Compare after Google marks the rollout complete

Google recommends waiting at least one full week after the update finishes before analyzing the change in Search Console. Compare that week with a week before the rollout began. Keep filters consistent and review Web, Image and Video search separately when they matter to the store. Check page and query changes before choosing an edit. [Google Search Central's core update guidance](https://developers.google.com/search/docs/appearance/core-updates)

For example, if a mug page loses clicks for size queries, check whether buyers can find the base diameter on the exact variant. Verify the dimension before rewriting the page and record which query and page prompted the change.

Choose **Product copy rewriting** if you need suggested edits, or **Keyword optimization** if you need help relating buyer phrases to page content.
