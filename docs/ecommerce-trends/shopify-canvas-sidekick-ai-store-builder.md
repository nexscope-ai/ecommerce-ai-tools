# Shopify Canvas: how to build and edit a store with Sidekick AI

**By Nexscope Team · Published and verified October 6, 2026**

**Shopify Canvas is an early-access design workspace where merchants can view store templates together, edit them directly, and ask Sidekick to build or change the theme.** Sidekick works on real theme files and Canvas renders the result interactively. It can accelerate design work, but current access, theme support, app blocks, localization, and file portability have important limits.

> **Key takeaways**
>
> - Canvas is in early access and is available only to certain Shopify stores on desktop.
> - It displays multiple store templates side by side and supports direct editing plus conversational changes with Sidekick.
> - Sidekick can create a new theme from a brand description or change a supported duplicated theme.
> - Shopify-developed and custom themes are supported; third-party themes are not.
> - Canvas currently cannot add or configure app blocks, customize themes by market, or translate theme content directly.
> - AI-assisted design does not remove the need to test product facts, accessibility, SEO, performance, analytics, and conversion paths before publishing.

## What is Shopify Canvas?

**Canvas is Shopify's new visual workspace for designing an entire online store with Sidekick.** Instead of opening one template at a time, a merchant can see store templates laid out together, pan across the site, zoom into a page, edit a block or text, and ask Sidekick for a broader change.

Shopify announced Canvas on October 1, 2026. It says Sidekick works directly on theme files, validates code, takes screenshots to inspect its work, and refines the result before handing it back. The page shown in Canvas is an interactive render of the store code rather than a static mockup.

This makes Canvas more than an image generator or a prompt-to-screenshot tool. It is an editing environment for a Shopify theme. That also means a merchant must review the same technical and business consequences that come with any real theme change.

## Who can use Shopify Canvas?

**Canvas is currently early access for certain stores and works only on desktop devices.** Shopify lists four basic requirements:

| Requirement | Current rule |
| --- | --- |
| Store access | Canvas must be enabled for the store |
| Device | Desktop only |
| Plan | A plan that includes theme customization |
| Staff permission | Online store > Themes > Edit code |
| Theme source | Shopify-developed or custom theme; no third-party themes |

Eligible merchants open Canvas from the Themes page in Shopify admin. If the option is not visible, Shopify's public documentation does not provide a universal self-service activation method. Treat the store as not yet enabled rather than promising immediate access.

## How do you build a Shopify store with Sidekick in Canvas?

**A merchant can create a new theme from a description or duplicate a supported theme and modify the copy.** Shopify documents this workflow:

1. Open **Online Store** from Shopify admin on a desktop device.
2. Create a new theme, or choose a supported theme and select **Duplicate in Canvas**.
3. Describe the brand and desired store to Sidekick when creating a new theme.
4. Review the templates Sidekick creates in Canvas.
5. Edit text, block settings, colors, typography, and other theme settings directly where supported.
6. Ask Sidekick to make changes that are not available in the visible block settings.
7. Preview different products, collections, pages, and screen sizes.
8. Review the change list and publish only after QA.

Changes are saved automatically, but they are not visible to customers until the merchant publishes them. For an existing published Canvas theme, Shopify says the store continues to show the prior live version until the merchant clicks Update and then publishes the changes.

## Shopify Canvas vs the theme editor: what is different?

**Canvas adds a whole-store visual surface and Sidekick collaboration; it does not replace the existing theme editor yet.** The two environments also do not edit the same copied theme in parallel.

| Question | Shopify Canvas | Existing theme editor |
| --- | --- | --- |
| Primary view | Multiple templates in a zoomable workspace | A selected page or template |
| AI collaboration | Sidekick can build and change theme files | Sidekick capabilities depend on the existing editor experience |
| Direct editing | Blocks, settings, text, and theme settings where supported | Established theme-editor controls |
| Theme copy | A Canvas duplicate becomes a separate theme | The original remains separately editable |
| Availability | Early access, certain stores, desktop | Standard store experience subject to plan and theme |
| Current role | Experimental design and build workspace | Existing production editing workflow |

Shopify warns that a duplicated theme and its original are separate. Changes made in one do not appear in the other. Before publishing, confirm that the selected theme contains the latest approved work.

## What are the current Shopify Canvas limitations?

**The early-access limitations affect maintainability, apps, localization, and portability.** They should be checked before a team commits a production redesign to Canvas.

- **No third-party themes:** Shopify-developed and custom themes are supported, but third-party themes are not.
- **No theme-file download:** Shopify says themes edited in Canvas cannot be downloaded.
- **No future theme updates:** a theme edited in Canvas does not receive theme updates.
- **No app blocks or app embeds:** they cannot currently be added or configured in Canvas.
- **No per-market customization:** a theme cannot be customized for different markets in Canvas.
- **No direct translation:** use Shopify's Translate & Adapt workflow instead.
- **No manual new block:** ask Sidekick to add a block; some older themes also limit direct text editing.
- **Different undo behavior:** when Sidekick makes a change, the normal undo history is cleared; use theme history to restore an earlier version.

These are not minor details for a multilingual store, a store that depends on theme-app extensions, or a team that requires downloadable source files. Confirm the operating model before moving the production theme into the Canvas workflow.

## What should you include in a good Sidekick design prompt?

**Describe the business constraints Sidekick must preserve, not only the visual mood.** A useful starting brief includes:

1. Brand positioning and the primary customer.
2. The product categories and the most important purchase questions.
3. Required templates: home, collection, product, cart, editorial, and policy pages.
4. Existing brand colors, typography, image rules, and accessibility requirements.
5. Mobile priorities and the elements that must remain above the fold.
6. Required app or custom-code dependencies that Canvas may not support directly.
7. Facts and claims that must not be changed without approval.
8. Analytics, consent, and conversion events that must survive the redesign.

Ask for one bounded change at a time when the risk is high. “Make the product page clearer for size selection without changing product copy or app blocks” is easier to verify than “redesign everything and improve conversions.”

## How should merchants test a Canvas theme before publishing?

**Build on an unpublished theme or duplicate and run a structured QA pass before publishing.** A visually convincing homepage is not enough.

| Test area | What to verify |
| --- | --- |
| Product accuracy | Titles, variants, prices, included items, claims, availability |
| Navigation | Menus, search, collection filters, breadcrumbs, internal links |
| Conversion | Variant selection, add to cart, discounts, cart, checkout handoff |
| Mobile | Layout, tap targets, sticky elements, media, text wrapping |
| Accessibility | Heading order, contrast, keyboard use, labels, alt text |
| SEO | Title and description output, one H1, canonical, structured data, crawlable links |
| Performance | Image sizes, scripts, layout shifts, page responsiveness |
| Apps | Reviews, subscriptions, personalization, chat, consent, analytics |
| Markets | Currency, language, regional content, duties, shipping and policies |

Use theme history to save and compare meaningful checkpoints. Test the live storefront separately after publishing because Canvas preview behavior alone does not prove that every production integration or analytics event works.

## Does Shopify Canvas improve SEO or conversion automatically?

**No automatic ranking or conversion improvement is documented.** Canvas changes the design and code workflow. Search performance still depends on crawlability, content, metadata, structured data, internal links, mobile experience, speed, authority, and search intent. Conversion still depends on the product, offer, trust, price, UX, and traffic quality.

After a Canvas redesign, compare the same pre- and post-publish checks:

- indexed URL and canonical behavior;
- page title, meta description, H1, and heading structure;
- Product structured data and visible price/availability agreement;
- Core Web Vitals and key page-load regressions;
- product-page engagement, add-to-cart, checkout start, and completed order;
- device, market, and traffic-source segments.

The [ecommerce product-page SEO audit guide](../../website-seo-audit-guide/) provides a page-level QA sequence. That is a separate editorial workflow; Nexscope is not part of Shopify Canvas and does not control Sidekick's output.

## What should Shopify teams do now?

**Use Canvas for a bounded theme experiment before considering a full production rebuild.** Start with one unpublished theme, one product template, and a written acceptance checklist. Confirm early-access eligibility, theme source, app dependencies, localization needs, and source-file requirements first.

Canvas can make a store-wide direction easier to see and help a merchant iterate with Sidekick. Its value still depends on the team's ability to recognize inaccurate product content, inaccessible layouts, broken app behavior, and performance regressions before they reach shoppers.

## Frequently asked questions

### What is Shopify Canvas?

Shopify Canvas is an early-access theme design workspace that displays store templates together and lets merchants edit directly or work with Sidekick to create and change theme code.

### How do I get Shopify Canvas access?

Canvas is currently available only to certain stores. Eligible users open it from the Themes page on desktop and need the Online store > Themes > Edit code staff permission.

### Does Canvas replace the Shopify theme editor?

No. Shopify says Canvas is not replacing the existing editor yet. A duplicated Canvas theme and its original are separate and can follow different editing paths.

### Can Canvas edit a third-party Shopify theme?

Not currently. Shopify says Canvas works with Shopify-developed and custom themes, but not third-party themes.

### Can I download a theme after editing it in Canvas?

Shopify says themes edited in Canvas cannot be downloaded and do not receive theme updates. Teams that require portable theme files should account for this before committing to the workflow.
